# CNN fast benchmark artifacts

Generated by:

```bash
python src/paper/run_paper_experiments.py fast-benchmark
```

These files are **small** (JSON + PNG) and **safe to commit** for your paper or CI. They summarize a **short** run (subset training, capped eval batches, fewer PGD steps) — see `meta` in `table2_asr.json`.

**Not committed:** model weights under `paper_checkpoints/` (see root `.gitignore`).

**Push to GitHub:** these paths are not ignored; add and commit them:

```bash
git add cnn_paper_benchmark/
git commit -m "Add CNN fast benchmark results for paper"
```

Re-run locally to refresh numbers before submission:

```bash
python src/paper/run_paper_experiments.py fast-benchmark
# or reuse checkpoints (~50s on CPU):
python src/paper/run_paper_experiments.py fast-benchmark --skip_train
```
